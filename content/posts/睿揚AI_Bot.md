## 一、 基本與常用節點類型

- **發送訊息**
  - **使用時機**：當機器人想向使用者發送訊息時使用。
  - **特性**：支援多種訊息類型（文字、圖片、影片、音訊、表格、表單等）。執行完該節點後，會立即執行下一個節點。

- **文字輸入**
  - **使用時機**：當機器人需要等待使用者回覆訊息或填寫資料時使用。
  - **特性**：會等待使用者輸入或選擇後才會執行下一個節點。支援「驗證」與「錯誤回應」設定（如檢查是否為數字、正規表示式比對等），並可在輸入框上方顯示「快速回覆按鈕」。

- **呼叫 API (Raw) / 呼叫 API (Key-Value)**
  - **使用時機**：需要與其他系統透過 API 方式進行介接或存取資料時使用。
  - **特性**：兩者主要區別在於主體類型（BodyType）與主體（Body）格式不同（Raw 支援 JSON、純文字等；Key-Value 支援 form-data 等）。

- **決策與變數設定**
  - **使用時機**：用來進行「變數操作」以及判斷節點「下一步」要往哪一個節點繼續執行的條件判斷。

---

## 二、 流程控制與腳本呼叫相關節點

- **呼叫腳本**
  - **使用時機**：當前腳本流程中需要呼叫其他腳本時。
  - **特性**：被呼叫的腳本結束後，會返回目前腳本的當前節點繼續執行。

- **切換腳本**
  - **使用時機**：對話流程由目前腳本切換至其他腳本執行。
  - **特性**：直接跳至被呼叫的腳本，執行後不會返回目前腳本。

- **結束目前的腳本**
  - **使用時機**：結束目前的腳本，返回上一層腳本，並可選擇將變數資料回傳輸出。

- **結束所有腳本**
  - **使用時機**：結束機器人的所有對話執行腳本，再次對話時會重新由起始腳本開始。

- **其他相關呼叫**
  - **切換腳本 / 呼叫多個 API / 批次呼叫 API / 呼叫模組**：用於處理更複雜的模組化調用或連續性請求。

---

## 三、 其他進階與輔助節點

- **發送事件**：用於發送事件相關設定。
- **資料處理**：透過自訂程式碼（如 JavaScript 表達式）來處理資料與運算。
- **偵錯**
  - **使用時機**：使用者在前端不會看到此訊息，專門提供給開發者在「模擬測試」時觀察資料與變數內容使用，不會干擾腳本流程。
- **擴充插件**：掛載擴充功能或插件使用。
